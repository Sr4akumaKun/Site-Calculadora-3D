# Pece3D — Calculadora de Preço para Impressão 3D

Calculadora em HTML único (sem dependências) que calcula o preço de venda de peças impressas em 3D, considerando:

- Filamento (multicor, desperdício)
- Energia elétrica
- Desgaste e manutenção da impressora
- Mão de obra
- Custos fixos do negócio
- Materiais extras
- Taxa de falhas
- Impostos, taxas de plataforma e margem/markup de lucro

## Como usar

Abra o `index.html` no navegador. Os dados ficam salvos no próprio navegador (localStorage).

## Publicar no GitHub Pages

1. Envie `index.html` e `README.md` para um repositório.
2. Em **Settings → Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. O site ficará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
